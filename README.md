# AI-Based Bug Analysis System

## Overview

The AI-Based Bug Analysis System is a multi-agent software defect analysis application.

It accepts bug reports, stack traces, and error logs and provides structured analysis including:

- Severity
- Priority
- Affected component
- Log analysis
- Root cause hypothesis
- Duplicate/related bug detection
- Remediation recommendations

## Main Components

### Triage Agent

Determines:

- Severity
- Priority
- Affected component
- Confidence
- Reasoning

### Log Analysis Agent

Extracts:

- Exception type
- Error message
- Failure point
- Code path
- Confidence

### Root Cause Agent

Uses semantic retrieval from the historical defect knowledge base to generate a possible root cause and supporting evidence.

### Duplicate Detection Agent

Uses semantic similarity to identify:

- Duplicate bugs
- Related bugs
- New/unmatched bugs

### Remediation Agent

Provides actionable recommendations based on the analysis and available historical evidence.

## RAG Pipeline

The project uses:

- Sentence Transformers
- all-MiniLM-L6-v2
- FAISS
- Historical Mozilla bug data

The current dataset is a development seed dataset.

## Limitations

The current implementation uses rule-based analysis for several agents and semantic vector search for historical defect retrieval.

The historical dataset is currently a development seed dataset, so duplicate detection and historical evidence are limited to the available records.

Recommendations generated by the system should be verified through code review and testing before applying fixes.
